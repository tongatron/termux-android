Come hostare una pagina web su Android con Termux

Guida rapida per pubblicare un sito statico da un telefono Android con Termux, senza root.

Questa pagina spiega la procedura in generale. I dettagli del setup di questo telefono (IP, tunnel, incidenti) sono nel repo, non pubblicati qui.

Cosa serve

  • Un telefono Android con Termux installato (Play Store o F-Droid).
  • Un Mac/PC sulla stessa rete (o via Tailscale) per lavorare da tastiera.
  • Per un URL pubblico: un account Cloudflare gratuito.

1. Setup iniziale in Termux

Sul telefono, apri l'app Termux:

pkg update && pkg upgrade -y
pkg install -y openssh python net-tools

openssh per lavorare da tastiera Mac/PC, python per il web server incluso, net-tools per le utility di rete.

2. Accesso SSH da Mac/PC

Nel telefono:

passwd        # password temporanea, serve solo a copiare la chiave
sshd
whoami        # segna l'utente, es. u0_a123

Sul Mac/PC, copia la chiave pubblica (porta 8022, non 22: Termux non ha privilegi per la porta SSH standard):

ssh-copy-id -p 8022 -i ~/.ssh/id_ed25519.pub <utente>@<ip-telefono>
ssh -p 8022 <utente>@<ip-telefono>

3. Servire la pagina

mkdir -p ~/www
# copiaci dentro index.html e gli altri file statici
python -m http.server 8080 --directory ~/www --bind 127.0.0.1

--bind 127.0.0.1 limita il server al loopback, raggiungibile solo tramite un tunnel. Per copiare i file dal Mac/PC:

scp -P 8022 index.html <utente>@<ip-telefono>:~/www/index.html

4. Tenerlo acceso in background

Il solo nohup ... & non basta: chiudendo la sessione SSH, Termux termina comunque il processo. Serve setsid per staccarlo davvero:

setsid nohup python -m http.server 8080 --directory ~/www --bind 127.0.0.1 \
  < /dev/null > ~/webserver.log 2>&1 & disown

5. Pubblicarlo su internet con Cloudflare Tunnel

pkg install cloudflared

Opzione rapida (URL casuale, per provare)

Nessun login richiesto, ma l'URL cambia a ogni riavvio:

cloudflared tunnel --url http://127.0.0.1:8080

Opzione stabile (dominio fisso)

Un named tunnel richiede login la prima volta:

cloudflared tunnel login
cloudflared tunnel create <nome-tunnel>
cloudflared tunnel route dns <nome-tunnel> tuo-sottodominio.tuodominio.org

setsid nohup cloudflared tunnel run <nome-tunnel> \
  < /dev/null > ~/cloudflared.log 2>&1 & disown

6. Tenere Termux vivo a schermo spento

termux-wake-lock

Mantiene sveglia la CPU a schermo spento. Sul telefono, disattiva anche le restrizioni batteria:

Impostazioni → App → Termux → Batteria → Nessuna restrizione
Impostazioni → App → Termux → Avvio automatico (se presente, es. MIUI)

7. Avvio automatico al riavvio del telefono

Dalla versione 2024.10.24 di Termux, ogni script eseguibile in ~/.termux/boot/ parte da solo al riavvio (funzione ex Termux:Boot, ora integrata):

mkdir -p ~/.termux/boot
cat > ~/.termux/boot/start-services <<'EOF'
#!/data/data/com.termux/files/usr/bin/bash
termux-wake-lock
sshd
setsid nohup python -m http.server 8080 --directory ~/www --bind 127.0.0.1 \
  < /dev/null > ~/webserver.log 2>&1 & disown
setsid nohup cloudflared tunnel run <nome-tunnel> \
  < /dev/null > ~/cloudflared.log 2>&1 & disown
EOF
chmod +x ~/.termux/boot/start-services

Limiti da tenere a mente

  • Non è un server 24/7 affidabile come hardware dedicato: Android può uccidere Termux in background, specie su MIUI/Xiaomi.
  • Android 15+ blocca ip addr/ifconfig a Termux (SELinux nega l'accesso netlink).
  • /tmp non esiste in Termux: usare $TMPDIR.
  • L'IP locale via DHCP cambia nel tempo: per accesso stabile usare Tailscale o un IP fisso.
