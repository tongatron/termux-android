How to host a web page on Android with Termux

A quick guide to publishing a static site from an Android phone with Termux, without root.

This page explains the general procedure. Details about the setup of this phone (IP, tunnel, incidents) stay in the repository and are not published here.

Requirements

  • An Android phone with Termux installed (Google Play or F-Droid).
  • A Mac/PC on the same network (or connected through Tailscale) for keyboard-based administration.
  • For a public URL: a free Cloudflare account.

1. Initial Termux setup

Open the Termux app on the phone:

pkg update && pkg upgrade -y
pkg install -y openssh python net-tools

openssh for Mac/PC administration, python for the built-in web server, and net-tools for network utilities.

2. SSH access from a Mac/PC

On the phone:

passwd        # temporary password, only needed to copy the key
sshd
whoami        # note the username, e.g. u0_a123

On the Mac/PC, use port 8022, not 22: Termux cannot use the standard privileged SSH port.

ssh -p 8022 <termux-user>@<phone-ip>

3. Serve the page

mkdir -p ~/www
# copy index.html and the other static files here
python -m http.server 8080 --directory ~/www --bind 127.0.0.1

--bind 127.0.0.1 keeps the server on loopback, reachable through a tunnel. To copy files from the Mac/PC:

scp -P 8022 index.html <termux-user>@<phone-ip>:~/www/index.html

4. Keep it running in the background

nohup ... & alone is not enough: when the SSH session closes, Termux may still terminate the process. Use setsid to detach it:

setsid nohup python -m http.server 8080 --directory ~/www --bind 127.0.0.1 \
  < /dev/null > ~/webserver.log 2>&1 & disown

5. Publish it with Cloudflare Tunnel

pkg install cloudflared

Quick option (random URL)

No login is required, but the URL changes after a restart:

cloudflared tunnel --url http://127.0.0.1:8080

Stable option (fixed domain)

A named tunnel requires a first-time login:

cloudflared tunnel login
cloudflared tunnel create <nome-tunnel>
cloudflared tunnel route dns <tunnel-name> subdomain.yourdomain.org

setsid nohup cloudflared tunnel run <tunnel-name> \
  < /dev/null > ~/cloudflared.log 2>&1 & disown

6. Keep Termux alive with the screen off

termux-wake-lock

This keeps the CPU awake with the screen off. Also remove Termux battery restrictions:

Settings → Apps → Termux → Battery → No restrictions
Settings → Apps → Termux → Autostart (if available, e.g. MIUI)

7. Automatic startup after reboot

On Google Play Termux, executable scripts in ~/.termux/boot/ start at reboot through integrated boot support. F-Droid/GitHub installations use the Termux:Boot add-on:

mkdir -p ~/.termux/boot
cat > ~/.termux/boot/start-services <<'EOF'
#!/data/data/com.termux/files/usr/bin/bash
termux-wake-lock
sshd
setsid nohup python -m http.server 8080 --directory ~/www --bind 127.0.0.1 \
  < /dev/null > ~/webserver.log 2>&1 & disown
setsid nohup cloudflared tunnel run <nome-tunnel> \
  < /dev/null > ~/cloudflared.log 2>&1 & disown
EOF
chmod +x ~/.termux/boot/start-services

Command cheat sheet

CommandPurpose
sshdstart SSH on port 8022
pgrep sshdcheck whether SSH is active
termux-wake-lockkeep the CPU awake with the screen off
python -m http.server 8080 --directory ~/wwwserve the site on port 8080
setsid nohup <cmd> </dev/null >log 2>&1 & disownrun in the background after SSH closes
cloudflared tunnel --url http://127.0.0.1:8080start a quick public tunnel
pgrep -laf "http.server\|cloudflared\|sshd"check active services
scp -P 8022 file <user>@<host>:~/pathcopy a file to the phone

Limitations

  • This is not a dedicated 24/7 server: Android may kill Termux in the background, especially on MIUI/Xiaomi.
  • Android 15+ may block ip addr/ifconfig in Termux (SELinux blocks netlink access).
  • /tmp may not exist in Termux: use $TMPDIR.
  • The DHCP address changes: use Tailscale or a fixed address for stable access.
